# Lottery Domain Rules & Conventions (กฎสำคัญของระบบหวย)

## 1. "งวดวันที่" (Round Date) ต้องเป็น "วันที่ปิดรับแทง / วันที่ออกรางวัล" เสมอ (ห้ามใช้วันที่เปิดรับแทงเด็ดขาด)

### บริบทและความสำคัญ
ในวัฒนธรรมการเล่นหวย (ทั้งหวยรัฐบาลไทย หวยลาว หวยฮานอย ฯลฯ) "งวดวันที่" หมายถึงวันที่ออกรางวัลและปิดรับแทงเท่านั้น เช่น "งวดประจำวันที่ 16 เมษายน" แม้ว่าเจ้ามือจะเปิดรับแทงล่วงหน้าตั้งแต่วันที่ 15 เมษายน ก็ตาม สมาชิกและเจ้ามือจะเรียกงวดนี้ว่า **"งวดวันที่ 16"** เสมอ หากระบบแสดงเป็นวันที่ 15 จะทำให้ผู้ใช้สับสนอย่างรุนแรง

### กฎข้อบังคับในการเขียนโค้ด (Mandatory Coding Standards)
1. **การสร้างงวด / แก้ไขงวด (`Dealer.jsx`)**:
   - `round_date` ที่บันทึกในตาราง `lottery_rounds` ต้องบันทึกเป็น `roundForm.close_date` เสมอ ห้ามใช้ `roundForm.open_date` เด็ดขาด
2. **การดึงวันที่งวดมาแสดงผล**:
   - ต้องให้ความสำคัญสูงสุดกับวันที่ปิดรับแทง โดยตรวจสอบตามลำดับ:
     `close_time` -> `close_date` -> `round_date` -> `open_time`
   - ใช้ฟังก์ชันส่วนกลาง `getRoundCloseDate(roundOrTimestamp)` จาก `src/utils/crossRoundOffsetCalculator.js` เสมอ
3. **การแปลงเวลาและ Timezone**:
   - เซิร์ฟเวอร์และฐานข้อมูลอาจเก็บ `close_time` เป็น UTC ISO string เช่น `2026-04-16T08:30:00Z`
   - การดึงวันที่ต้องคำนวณในไทม์โซนประเทศไทย (`Asia/Bangkok` / UTC+7) เสมอ (เช่นใช้ `.toLocaleDateString('en-CA', { timeZone: 'Asia/Bangkok' })`) เพื่อป้องกันปัญหาวันที่เลื่อนข้ามวัน
4. **การคำนวณหักล้างยอดข้ามงวดและการจับคู่งวดเก่า**:
   - `findMemberPastUnpaidRounds` และ `findUpstreamPastUnpaidRounds` ต้องรับ `roundHistory` เพื่อนำ `close_time` ของงวดจริงมาแก้ไข/แทนที่ `round_date` ที่อาจบันทึกผิดพลาดในอดีต
